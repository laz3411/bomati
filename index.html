BUMATI 이용약관

시행일 2026년 9월 13일 · 버전 1.0

1. 서비스 목적

BUMATI는 버스 위치 확인, 하차 예약 및 하차 알림을 제공하는 시뮬레이션 기반 서비스입니다. 실제 교통 상황과 차이가 발생할 수 있습니다.

2. 계정 이용

회원은 본인의 이메일로 계정을 생성하며 계정과 비밀번호를 안전하게 관리해야 합니다. 타인의 계정을 무단으로 이용해서는 안 됩니다.

3. 위치 및 이용정보

서비스 제공을 위해 게임 내 위치, 선택한 버스·정류장, 하차 예약 상태를 처리할 수 있습니다. 비밀번호는 Firebase Authentication에서 관리하며 BUMATI Realtime Database에 저장하지 않습니다.

4. 서비스 제한

네트워크, Firebase 또는 Roblox 상태에 따라 위치와 알림이 지연될 수 있습니다. 안전과 실제 하차 판단을 앱 알림에만 의존해서는 안 됩니다.

5. 회원 탈퇴

회원은 계정 메뉴에서 탈퇴할 수 있습니다. 탈퇴 시 Firebase 인증 계정과 계정 프로필이 삭제되며 복구할 수 없습니다.

거동 불편 장애인 인증

장애인 하차벨 기능 약관 버전 1.0 · 시행일 2026년 9월 13일

해커톤 시연용 인증입니다. 정부기관이나 복지카드 발급기관에 조회하지 않으며 공식 장애인 인증을 대신하지 않습니다. 아래 증빙 정보는 현재 화면에서 형식만 확인하고 Firebase로 전송하거나 저장하지 않습니다.

장애인 하차벨 기능 약관 및 민감정보 안내 보기

1. 기능 목적

인증이 활성화된 계정이 저상버스 하차 예약 또는 지금 하차하기를 사용하면 일반 벨 대신 장애인 하차벨 신호를 보냅니다.

2. 저장 항목

Firebase에는 계정 UID, 인증 활성 상태, 무작위 인증 ID, 약관 버전과 동의 시각만 저장합니다. 이 화면에 입력한 성명, 증빙 유형 및 식별번호 마지막 4자리는 형식 확인 후 즉시 폐기하며 서버에 저장하지 않습니다.

3. 보유 및 취소

인증 상태는 사용자가 인증을 취소하거나 회원 탈퇴할 때까지 사용합니다. 계정 메뉴에서 언제든 인증을 취소할 수 있으며 취소 즉시 인증 상세정보와 동의 이력을 삭제하고 일반 하차벨 방식으로 전환합니다.

4. 동의 거부

별도 동의를 거부할 수 있으며 이 경우 일반 하차벨과 기본 지도 기능은 계속 이용할 수 있지만 장애인 하차벨 자동 선택 기능은 사용할 수 없습니다.

5. 시연 범위

현재 버전은 공식 행정정보 조회가 없는 시연용입니다. 실제 서비스에서는 관계기관 인증 연계, 법률 검토, 접근통제 및 개인정보 보호 절차가 추가로 필요합니다.

장애인 하차벨 기능 사용 중
